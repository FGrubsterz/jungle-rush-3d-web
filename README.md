# Jungle Rush 3D — web build

The playable build of **Jungle Rush 3D**, a 3D platformer for Plejarena:
32 levels in 8 worlds, 10 skins, keyboard + mouse or touch controls on phones.

This repository holds only the built static files (produced by `npm run build`
in the game's source project). It is served by Render as a static site
(`render.yaml`, publish directory `.`).
