# Jungle Rush 3D — web build

The playable build of **Jungle Rush 3D**, a 3D platformer for Plejarena:
100 levels in 10 worlds, 10 skins, keyboard + mouse or touch controls on phones,
a full-screen button, and a home-screen app icon.

This repository holds only the built static files (produced by `npm run build`
in the game's source project). It is served by GitHub Pages and can also be
served by Render as a static site
(`render.yaml`, publish directory `.`).
